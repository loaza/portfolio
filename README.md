# Pich Sann — portfolio website

Live at **https://ideaspot.online** (published automatically by GitHub Pages on every commit to `main`).

> The site is **online**: `index.html` is the full portfolio, including the shop (orders open on 1 December 2026).

## Folders

```
index.html            the page visitors see (the full portfolio)
pictures/
  canvas/             Canvas, 2025          canvas.jpg, canvas-2 … canvas-5
  amelie/             Amelie, 2026          amelie-1 … amelie-4
  boy/                Boy, 2026             boy.jpg, boy-2 … boy-7
  analysis/           Analysis, 2025        canvas-analysis-1 … 6
  untitled/           Untitled, 2026        girl-1, girl-2
  video/              video covers          video-cover.jpg, -2, -3
.github/workflows/    the publish step (don't edit)
```

## Adding photos

- Put each photo in the folder of its series, for example `pictures/boy/boy-8.jpg`.
- Use lowercase names with dashes, no spaces.
- Keep photos web-sized: about 2000 px on the long side, under 1 MB.
- A new photo only appears on the site once `index.html` refers to it.

## Rules

- Don't put files in the main folder except `index.html` and `README.md`.
- Before you change something, check the latest commits so you don't overwrite someone else's work.
